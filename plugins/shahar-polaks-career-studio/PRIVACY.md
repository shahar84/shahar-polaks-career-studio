# Privacy

CVs can include personal information. Users should remove unnecessary sensitive details before upload. This plugin does not require identity documents, passwords, financial information, medical records, or unrelated sensitive data. It does not make claims about platform data retention, deletion, encryption, or confidentiality.

## Browser-assisted tasks

When requested, Career Studio can use available browser access to read relevant
profile, job, and company pages. Keep review tasks limited to relevant content.
Complete sign-in in the browser rather than sharing credentials in chat. Uploading
candidate material to a website requires a specific user request.
