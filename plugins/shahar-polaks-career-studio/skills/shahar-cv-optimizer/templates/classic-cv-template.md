# Classic CV layout specification

Pair with the [ATS content template](ats-cv-template.md) and persona-specific section order. Inspect both pages of [classic-reference.pdf](../assets/cv-design-examples/classic-reference.pdf) before reproducing the theme. The PDF is a visual reference, not editable candidate content.

## Visual system

| Element | Specification |
| --- | --- |
| Page | A4 portrait, white background, approximately 48 pt side margins |
| Name | Newsreader Semi Bold, about 27 pt; ink `#1A1614` |
| Role-focus line | Public Sans, about 9 pt, restrained letter spacing; muted `#57504C` |
| Body | Public Sans, normally 10.5-11 pt in the final CV; ink `#1A1614` |
| Summary | Optional Newsreader italic, about 11 pt, muted `#57504C`; use upright text if it improves readability |
| Section headings | Public Sans Semi Bold, about 9 pt, uppercase with modest tracking; muted `#57504C` |
| Role headings | Public Sans Semi Bold, about 11 pt; ink `#1A1614` |
| Accent | Wine `#6D2D3F` for a thin top rule or restrained employer emphasis |
| Secondary text | Muted gray `#8B8480` for dates and nonessential metadata; darken if needed for legibility |
| Separators | Fine light-gray rules, generous section spacing, small unobtrusive bullets |

Use installed, appropriately available fonts. If Newsreader/Public Sans are unavailable, use a readable serif/sans pair such as Georgia and Arial; disclose material visual differences rather than claiming an exact match.

## Composition

The reference places the name at upper left and contact details at upper right, followed by a thin wine rule. Keep contact details in the document body and in logical text order; use an inline contact row if the right-aligned arrangement breaks extraction. Keep the summary short and give experience the most space.

The sample has a narrow left date gutter, with the main role text starting about 125 pt from the page's left edge. Use this only if date-role association survives text extraction. Otherwise place dates on the role line. Keep each role and its bullets as one continuous reading block.

Use small uppercase section labels, subtle separators, and restrained white space. Continue older experience naturally on page two if needed. Skills are grouped as readable text lines; do not reproduce a visual grid as a decorative table. Optional page numbering or a redundant candidate name may appear in the footer.

Follow [PDF design and verification](../references/pdf-design-guidelines.md). Do not copy sample facts, force two pages, or shrink body text to reproduce the sample's exact line count.
