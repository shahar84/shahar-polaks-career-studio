# Warm CV layout specification

Pair with the [ATS content template](ats-cv-template.md) and persona-specific section order. Inspect both pages of [warm-reference.pdf](../assets/cv-design-examples/warm-reference.pdf) before reproducing the theme. Use directly when requested; no prior Classic approval is needed.

## Visual system

| Element | Specification |
| --- | --- |
| Page | A4 portrait, white background, approximately 48 pt side margins |
| Name | Bodoni Moda Semi Bold, about 30 pt; brown-black `#2F2823` |
| Body | Jost, normally 10.5-11 pt in the final CV; warm dark text `#5B5049` |
| Role-focus line | Jost Medium, about 11 pt; muted brown `#8A5F4E` |
| Section headings | Jost Semi Bold, about 8.5-9 pt, uppercase; muted brown `#8A5F4E` |
| Role headings | Jost Semi Bold, about 11 pt; brown-black `#2F2823` |
| Accent | Muted brown `#8A5F4E` for headings/employer emphasis; pale taupe `#D4BEB1` for decorative bullets or rule segments |
| Secondary text | Warm gray `#8B7D73` for dates and nonessential metadata; darken if needed for legibility |
| Separators | Fine pale-taupe section rules and a slightly stronger brown/taupe top rule |

Use installed, appropriately available fonts. If Bodoni Moda/Jost are unavailable, use a readable editorial serif and sans pair, such as Georgia and Arial. State material visual differences outside the CV rather than claiming exact fidelity.

## Composition

Follow the Warm reference's prominent serif name, role-focus line, compact contact row, and restrained top rule. Keep the page white; the theme comes from typography and small brown accents, not a beige canvas or decorative panels.

Use one main content column with the reference's secondary date gutter, placing the main role text about 147 pt from the page's left edge when this preserves logical extraction. Otherwise put dates inline. Keep the body alignment consistent across Summary, Experience, Skills, and Education.

Use small taupe bullets sparingly and keep all essential text dark enough to read. Skills remain text lines, not a visual rating system or layout table. Use one or two pages according to supported evidence, preserving comfortable leading and section spacing.

Follow [PDF design and verification](../references/pdf-design-guidelines.md). Never reuse sample facts or claim that the reference was inspected unless both pages were actually reviewed.
