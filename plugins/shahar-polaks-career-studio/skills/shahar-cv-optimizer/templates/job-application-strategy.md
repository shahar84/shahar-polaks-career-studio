# Application strategy template

Create this only when requested. Use the candidate's target, constraints, supported experience, and available job evidence.

## Priority

State the qualitative fit and the strongest supported positioning. Distinguish must-have concerns from preferred-skill gaps. If no posting is supplied, state that the plan is provisional.

## Materials

List the small number of concrete edits needed for the CV, LinkedIn, portfolio, or interview examples. Include only deliverables relevant to the request. Keep unresolved facts outside application-ready material.

## Actions

Prioritize practical steps the user can take now, such as confirming a key responsibility, selecting a relevant project, clarifying a role requirement, or preparing a supported story. Tailor cadence to stated availability; do not invent a daily application quota or claim a conversion rate.

## Outreach and follow-up

Draft outreach only when asked. Use the candidate's real relationship and experience, and state a clear, proportionate request. Do not invent referrals, mutual contacts, recruiter interest, or hiring urgency. Sending messages or submitting applications requires authorization for the action and destination.
