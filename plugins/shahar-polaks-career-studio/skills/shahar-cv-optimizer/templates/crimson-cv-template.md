# Crimson CV layout specification

Pair with the [ATS content template](ats-cv-template.md) and persona-specific section order. Inspect both pages of [crimson-reference.pdf](../assets/cv-design-examples/crimson-reference.pdf) before reproducing the theme. Use directly when requested; no prior Classic approval is needed.

## Visual system

| Element | Specification |
| --- | --- |
| Page | A4 portrait, white background, approximately 48 pt side margins |
| Name | Bodoni Moda Semi Bold, about 30 pt; dark ink `#10151F` |
| Body | Jost, normally 10.5-11 pt in the final CV; text `#3F4753` |
| Role-focus line | Jost Medium, about 11 pt; burgundy `#B3213C` |
| Section headings | Jost Semi Bold, about 8.5-9 pt, uppercase; burgundy `#B3213C` |
| Role headings | Jost Semi Bold, about 11 pt; dark ink `#10151F` |
| Accent | Burgundy `#B3213C` for headings/employer emphasis; restrained red `#DE4B5F` for decorative bullets or rule segments |
| Secondary text | Gray `#737D8C` for dates and nonessential metadata; darken if needed for legibility |
| Separators | Thin pale-gray section rules; a slightly stronger segmented burgundy/red/dark top rule |

Use installed, appropriately available fonts. If Bodoni Moda/Jost are unavailable, use a readable editorial serif and sans pair, such as Georgia and Arial. State material visual differences outside the CV rather than claiming exact fidelity.

## Composition

Use a prominent serif name, the role-focus line below it, and one compact contact row. Keep the top rule as a restrained accent; do not add a banner, sidebar, portrait, logo, or decorative panels.

The reference uses one main text column with a secondary date gutter: the main role body begins about 147 pt from the page's left edge. Keep dates visually associated with their role, and verify extraction order. Use inline dates if necessary. The same body alignment runs through Summary, Experience, Skills, and Education.

Use small red square bullets only if they remain real text or harmless decoration beside selectable bullet text. Keep skills in readable grouped lines and maintain strong contrast for all essential information. Let relevant content determine the page count; the sample's two-page arrangement is not compulsory.

Follow [PDF design and verification](../references/pdf-design-guidelines.md). Never reuse the reference candidate's facts or claim visual inspection when only this specification was read.
