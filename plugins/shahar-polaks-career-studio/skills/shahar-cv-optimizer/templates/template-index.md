# Template index

Select a content structure first, then a visual theme when a file or designed CV is requested. Read the selected files before writing. Templates specify structure and style; none supplies candidate facts.

## CV content

Use the [ATS content template](ats-cv-template.md) and the [persona guidance](../references/candidate-personas.md). Adapt section order:

| Primary persona | Start with | Then prioritize |
| --- | --- | --- |
| Junior | Relevant skills and selected projects or internships | Education and other experience that supplies transferable evidence |
| Career switcher | Short role-focused summary and direct evidence in the new field | Prior experience with its original titles, relevant skills, retraining |
| Experienced IC | Summary and reverse-chronological experience | Technical depth, ownership, outcomes, skills, education |
| Manager or executive | Summary and leadership experience | People scope, delivery, technical judgment, business partnership, education |

An international target modifies relevant context, spelling, and format; it does not replace the experience-based persona. Remove unsupported or empty sections.

## Visual themes

| Theme | Specification to read | PDF to inspect | Use |
| --- | --- | --- | --- |
| Classic | [Classic specification](classic-cv-template.md) | [Classic reference](../assets/cv-design-examples/classic-reference.pdf) | Default; serif name, restrained wine accent, quiet hierarchy |
| Crimson | [Crimson specification](crimson-cv-template.md) | [Crimson reference](../assets/cv-design-examples/crimson-reference.pdf) | When requested; editorial serif name and burgundy/red accents |
| Warm | [Warm specification](warm-cv-template.md) | [Warm reference](../assets/cv-design-examples/warm-reference.pdf) | When requested; editorial serif name and muted brown accents |

Inspect both reference pages for the chosen theme. Follow [document design and verification](../references/pdf-design-guidelines.md). If the PDF cannot be inspected, use its written specification and disclose that limitation. Do not require Classic before a requested alternative. A text-only CV uses the content template without pretending that a visual theme was rendered.

Outside the candidate document, identify the template used in one brief sentence, for example: "Used the ATS content template with executive section order and the Warm layout." Only say the PDF reference was followed or visually checked when it actually was.

## Editable documents and PDF export

Use the [bundled document renderer](../references/document-export.md) to turn the candidate's supported content into an editable DOCX in Classic, Crimson, or Warm. Preserve the selected persona's section order in the structured input. PDF export uses the same DOCX layout when LibreOffice is available. The renderer implements each theme with a single reading column and inline dates; it is not a pixel-perfect copy of the reference PDFs.

Prepare the input internally from the evidence inventory. Never reuse the fictional input example as candidate facts. Keep confirmation questions outside the document and inspect the final pages and extracted text. Follow [Hebrew document guidance](../references/hebrew-documents.md) when the user asks for Hebrew output.
