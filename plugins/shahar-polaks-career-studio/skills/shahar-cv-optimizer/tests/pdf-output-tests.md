# PDF and template tests

- ATS content: verify standard headings, selectable text, supported facts, and one logical reading order. Persona-specific order is allowed.
- Classic default: verify the selected content template, persona order, Classic specification, and both Classic reference pages were actually read or inspected before reproducing the theme. Inspect the generated pages and final text extraction.
- Explicit Crimson or Warm: use the requested specification and reference directly without a mandatory Classic deliverable or approval. If rendering or reference access is unavailable, explain the limitation and still provide useful supported copy; do not invent a completed file.
- Template provenance: inspect the tool trace or accessed files. A final sentence claiming a template was used is not sufficient evidence. The selected reference must be inspected before claiming visual fidelity.
- Document quality: check clipping, orphan headings, small text, split roles, broken glyphs, date-role association, links, and sample-fact leakage. Do not force the sample's two-page count.
- Candidate copy: keep plugin branding, owner links, sample names, bracketed slots, and confirmation tags out of the submitted document. Put useful provenance and questions in companion notes.
